1
7:30 — Layer 1

Context OS

Your AI's memory and understanding of your business.

  • → claude.md — 20-30 lines: who you are, what you do, how to behave
  • → /context folder — business background, strategy, clients, SOPs
  • → /memory folder — persistent learnings: feedback, preferences, past decisions

"Point, don't dump. Keep the main file lean — link to detailed docs."

— Liam Ottley
2
10:00 — Layer 2

Data OS

All your business data consolidated into one accessible layer.

  • → Revenue from Stripe
  • → Calendar from Google
  • → Pipeline from your CRM
  • → Content metrics from socials

The key: live data, not stale exports. Your AI should answer "What's my MRR right now?" with accuracy.

3
12:00 — Layer 3

Tool Harness

Your AI's ability to take action.

  • → MCP servers connecting to external tools
  • → n8n workflows for complex automations
  • → API wrappers for services without direct integration

"The tools we're using today will look primitive in 6 months. Build for flexibility."

— Jordan Platten
4
14:00 — Layer 4

Intelligence Layer

Where Claude Code lives. Context + data + tools = decisions.

  • → Prompt engineering for specific tasks
  • → Skill files for repeatable workflows
  • → Takes context, data, tools and makes decisions

Without the other layers: a chatbot. With them: an operating system.

5
16:00 — Layer 5

Communication Layer

How you interact with your AI OS.

  • → Telegram bot for mobile access anywhere
  • → Scheduled tasks that run without you
  • → Alerts and notifications when things need attention

The front door to your entire system. Make it accessible, make it useful.
